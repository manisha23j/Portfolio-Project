PERSONAL PORTFOLIO WEBSITE

Project Name:
Portfolio-Project

Project Description:
This is a responsive personal portfolio website developed to showcase my skills, projects, resume,
and professional background as a Front-End Developer. The website is designed with a modern UI and
works properly on desktop, tablet, and mobile devices.

How to Run the Project:

Method 1 (Using VS Code Live Server):

1. Right click on index.html
2. Click "Open with Live Server"
3. The website will open automatically in your browser

Method 2 (Open directly in browser):

1. Right click on index.html
2. Click "Copy Path"
3. Open Google Chrome or Microsoft Edge (latest version)
4. Paste the copied path in the browser address bar
5. Press Enter
